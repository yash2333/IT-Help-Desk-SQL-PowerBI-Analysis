# IT Help Desk Analytics — SQL & Power BI

## 📌 Project Overview

An end-to-end **IT Help Desk Analytics** project using **MySQL/SQL and Power BI** to analyze case resolution performance, SLA compliance, service-agent efficiency, workload, priority risk, monthly trends, and case severity.

## 🎯 Key Analysis

- Average Resolution Time by Service Agent
- Agents with Above-Average Resolution Time
- Overall SLA Compliance
- Agent Performance Ranking
- SLA Compliance by Case Priority
- Month-over-Month Resolution Time Analysis
- Worst SLA-Performing Case Type by Month
- Monthly Resolved Cases and Running Total
- Weekly Agent Workload Analysis
- Impact of Case Severity on Resolution Time and SLA Compliance

## 🛠️ Tools & Technologies

**MySQL | SQL | Power BI | DAX | Data Analysis | Data Visualization**

## 💡 SQL Concepts Used

- Aggregate Functions
- CASE Statements
- CTEs
- INNER JOIN & CROSS JOIN
- Window Functions
- RANK()
- LAG()
- Running Totals
- Date & Time Functions
- STR_TO_DATE()
- TIMESTAMPDIFF()
- GROUP BY & ORDER BY
